# 第三部分　隐私与数据处理说明

> 本部分为**如实说明**，用于履行《中华人民共和国个人信息保护法》第十七条等规定项下的告知义务。**我们在此披露本系统全部与数据有关的实际行为，包括对您不利的部分。**

## 第十一条　总体原则：本地处理优先

本系统的文档处理（文本提取、OCR 识别、标准编号匹配、表格补全）默认**全部在您的本地计算机上完成**。我们不收集、不存储、不向任何服务器上传您所处理文档的内容。

**我们不做下列任何事情：**

- 不收集您的个人信息（姓名、联系方式、设备标识符等）；
- 不上传您的文档内容；
- 不进行用户行为跟踪、统计分析或广告推送；
- 不含遥测、崩溃上报或使用数据回传功能；
- 不含自动更新检查或任何形式的联网版本校验。

## 第十二条　临时文件的存储

| 项目 | 说明 |
|---|---|
| 存储位置 | 操作系统临时目录下的 `standard_system` 与 `standard_system_exports` 子目录（通常为 `%TEMP%\standard_system` 与 `%TEMP%\standard_system_exports`） |
| 存储内容 | 您上传或选择的原始文档、处理过程中生成的中间文件（如页面图像）、导出的结果文件 |
| 清理时机 | 本系统**正常退出时会自动清理**上述两个目录；若程序被强制终止或异常崩溃，临时文件可能残留 |
| 您的操作 | 您可以随时手动删除上述目录。若您处理的是敏感文档，我们建议您在关闭本系统后确认这两个目录已被清空 |

## 第十三条　处理日志

1. 本系统在运行过程中会生成处理日志，用于显示进度与排查问题。
2. 日志内容**包含您所处理文件的完整路径与文件名**。请注意：**文件名本身可能包含个人信息或敏感信息**。
3. 日志保存位置：
   - 界面上的"处理日志"面板（仅当次运行期间可见）；
   - 临时目录下的 `standard_system\stderr.log` 文件。
4. 日志**仅保存在您的本地计算机上**，不会发送给我们或任何第三方。
5. **在涉密模式下，日志中的文件路径会被自动脱敏处理**（替换为"路径已屏蔽"）。
6. 若您不希望日志留存，请在关闭本系统后清理上述临时目录。

## 第十四条　联网查询标准名称（**请注意：本功能默认开启**）

**本系统会在文档处理完成后，自动就本地字典未能匹配到的标准编号发起联网查询。此功能默认开启。**

| 项目 | 说明 |
|---|---|
| **发送的内容** | **仅标准编号**（例如"GB/T 1234"）。**不发送您的文档内容、文件名或任何其他信息。** |
| **访问的目标站点** | 中国境内：`openstd.samr.gov.cn`（全国标准信息公共服务平台）、`std.samr.gov.cn`<br>**境外**：`en.wikipedia.org`（维基百科）、`webstore.ansi.org`（美国国家标准学会）、`www.iso.org`（国际标准化组织） |
| **触发时机** | 处理完成后自动触发；您也可以在结果页面手动触发单条查询 |
| **接收方会记录的信息** | 上述站点的服务器会按其自身规则记录访问日志，其中**通常包括您的 IP 地址、访问时间**。我们无法控制这些站点的日志行为，它们的数据处理行为适用其各自的隐私政策 |
| **如何关闭** | 在"设置"页面取消勾选"处理完成后自动联网查询标准名称"。关闭后，本系统将不再发起上述任何请求，未匹配到的标准编号会以编号形式保留在结果中 |
| **涉密模式下** | **本功能被强制禁用，且不可开启** |

**特别提示：**

- 若您在**涉密网络、内网、或禁止外联的网络环境**中使用本系统，请在处理文档前**先关闭本功能**（或启用涉密模式），以免产生违反您所在单位规定的网络访问记录。
- 向境外站点发送请求时，由于请求由您的设备直接发起，**您的 IP 地址等信息会被境外接收方获取**。若您对此有顾虑，请关闭上述联网查询功能。
- **请求的标识方式**：本系统以自身的名称、版本号、源码地址与联系邮箱标识每一次请求，形如 `StandardProcessingSystem/<版本号> (+源码地址; contact: 联系邮箱)`。**我们不会伪装成浏览器或其他软件，也不会伪造请求来源地址（Referer）。** 这既是对目标站点的诚实，也可避免因伪造身份被站点封禁而影响您对这一功能的使用。

## 第十五条　本地 AI 服务（可选功能，默认不启用）

1. 若您配置了 AI 服务地址（可通过"设置"页面配置，或通过 `LOCAL_AI_URL` 环境变量指定），本系统会在表格补全时向该地址发送**文档中提取的文本片段**（包含该行内容及所在页码的上下文），用于补全标准名称。
2. 默认地址为 `http://localhost:8000/v1/chat/completions`。**默认仅允许配置为本地回环地址**；若要配置为非本机地址，需在设置中显式开启相应选项。
3. **若您将其配置为远程地址，则上述文本片段将被发送至该地址所指向的服务器。该服务器由您自行选择，其数据处理行为与我们无关，风险和后果由您自行承担。**
4. 您也可以配置 AI 服务的访问密钥（`LOCAL_AI_KEY`），该密钥仅在本系统向您指定的地址发起请求时使用。
5. **涉密模式下，本功能被强制禁用。**

## 第十六条　反馈功能（可选功能）

1. 本系统提供反馈入口。**仅当您主动填写并提交反馈时**，您所填写的文本才会被发送。
2. **本功能是否可用，取决于您的副本是否为构建者配置了反馈通道：**
   - **已配置时**：反馈内容通过**钉钉（DingTalk，阿里巴巴集团旗下服务）的 Webhook 通道**发送，数据将依据钉钉平台的隐私政策进行处理与存储；
   - **未配置时**（例如您自行从公开源代码构建的副本）：界面会明确提示本副本不支持该反馈方式，并引导您改用邮箱联系（见第三十九条）。**此时本系统不会发送任何数据。**
3. **发送的内容仅为您主动填写的反馈文本**，不包含您的文档内容、处理结果或其他个人信息。
4. **请您注意：请勿在反馈文本中填写任何个人信息、敏感信息、涉密信息，或您所处理文档的任何内容。**
5. **涉密模式下，本功能被禁用。**
6. **该反馈通道是单向的**：它只能把您填写的文字发送出去，**我们无法通过它读取您设备上的任何信息**，也不会因此获得您的文档内容或处理结果。
7. 您完全可以选择不使用反馈功能，这不会影响您使用本系统的任何核心功能。

## 第十七条　涉密模式

本系统提供一个可选的"涉密模式"，用于在需要严格隔离网络的环境中运行。**启用它会修改您操作系统的网络配置，请您在启用前充分了解下列内容。**

### 一、启用后本系统会做什么

| 行为 | 具体内容 |
|---|---|
| **拦截网络连接** | 本系统会在**应用层**拦截其自身的全部非本机网络连接（接管 socket 的对外连接接口），覆盖联网查询、本地 AI 服务与反馈功能。**这一层始终启用。** |
| **写入防火墙规则** | 本系统会**向 Windows 防火墙写入规则**，以阻断本系统的对外连接。**这是对您操作系统网络配置的实际修改。** 该操作需要管理员权限；若您当前不是管理员，本系统仅安装应用层防护，不会修改防火墙 |
| **日志脱敏** | 处理日志中的文件路径（含盘符路径、UNC 路径、POSIX 路径）会被替换为"路径已屏蔽" |
| **功能限制** | 上述联网功能全部不可用，且在涉密模式下无法通过设置重新开启 |

### 二、启用与关闭的确认流程

| 您的当前状态 | 本系统的行为 |
|---|---|
| **未以管理员身份运行，点击启用** | 本系统会先弹出确认提示，列明启用后的全部后果（提权、写入防火墙规则、拦截网络、禁用联网功能）。**只有您点击"确定"后**，本系统才会以管理员身份重启，并在重启后自动进入涉密模式 |
| **已以管理员身份运行，点击启用** | 点击开关即启用，不再弹出二次确认。设置页面在开关旁持续显示风险提示（说明启用后将强制禁用联网功能并激活防火墙） |
| **通过环境变量启用** | 若您在启动本系统前设置了环境变量 `CLASSIFIED_MODE`、`SECURITY_LEVEL` 或 `AIR_GAPPED`，本系统会在启动时**直接进入涉密模式并安装防火墙规则，不再另行询问** |
| **关闭涉密模式** | **同样需要管理员权限。** 若当前账户不具备管理员权限，关闭操作将被拒绝 |
