V1.2.1 → V2.0.0 更新内容

一、 支持的文档格式大幅扩展（重要）
	1. 现在可以直接处理 Excel（.xlsx / .xlsm / .xls）、PowerPoint（.pptx / .pptm）、纯文本与表格文本（.txt / .csv / .tsv / .md / .log / .rtf）。
	2. 修复了一个长期存在的问题：上述格式之前虽被"接受"，但实际会被静默忽略——上传后列表里看不到任何文件。现已打通全部入口（网页上传、选择文件、选择文件夹、拖拽、右键菜单）。
	3. 旧版 .xls 会自动调用本机 Excel 转换；若本机未安装 Excel，会明确提示"请另存为 .xlsx 后重试"，不再抛出看不懂的报错。
	4. 旧版二进制 .ppt 无法解析，会明确提示"请用 PowerPoint 另存为 .pptx 后重试"。
	5. PowerPoint 的备注页也会一并提取（部分标准号只写在备注里）。
	6. 支持 .docm / .xlsm / .pptm 等启用宏的格式变体。

二、 标准前缀与识别范围（重要）
	1. 修复了"前缀开关看起来生效、实际不生效"的问题。此前由于分组默认关闭，TB/T、ISO、Q/CR 等行业与国外标准会被**静默排除**，导致升级后识别结果变少且无任何提示；现已恢复。
	2. 设置页（设置 → 标准管理）会直接显示"实际生效前缀集合"，它与上方勾选框不一致时，以这里显示的为准。
	3. 若把所有分组/前缀全部关闭，系统会按设计回退到默认识别范围，并在界面与日志中明确说明，不再出现"关得越干净、认得越多"的困惑。
	4. 新增 JTG / JTS（公路行业）等带设计代字的标准号识别支持（需在设置中启用对应前缀）。
	5. 修复了英文正文被误判为标准号的问题：例如 "as 3"、"can 2"、"bs 5" 这类文本不再被当成标准编号（外国标准要求编号至少两位数字）。

三、 不再出现"界面卡住不动"（体验）
	1. 选择包含大量文件的文件夹时不再假死：改为先列出文件、界面立即可用，页数在后台并行统计并逐个显示；尚未统计完成的文件显示"统计中…"，不再假装成"1 页"。
	2. 已统计过的页数会被缓存，处理阶段直接复用，避免重复解析。
	3. 修复了一个严重的静默错误：当文件页数尚未统计完成就开始处理时，超长文件可能**只处理第 1 页且没有任何提示**。现在会按"到文件末尾"处理，或使用已统计的真实页数。

四、 结果展示与导出（重要）
	1. 导出会跟随结果表当前的搜索筛选，并询问"只导出匹配的 N 条 / 导出全部"；筛选结果为 0 条时会取消导出，不再默默导出全量数据。
	2. 有标准号查不到名称时，结果页会明确标注"其中 M 条未查到标准名称，已保留编号"，并以醒目颜色提示，不再隐藏在"处理完成"字样里。
	3. 联网查询即使一条都没有查到，也会正常收尾并说明未查到的条数（不再停留在"正在联网补充… 99%"）。

五、 安全加固（重要）
	1. PDF 预览组件升级到 pdf.js 4.10.38，修复旧版本的已知安全问题。
	2. 修复安装程序解压压缩包时的路径穿越问题（Zip Slip）。
	3. 修复了需要管理员权限时的命令注入问题（防火墙规则名、程序路径拼接）。
	4. OCR 安装包改为"内容哈希校验通过后才允许以管理员权限运行"，避免被替换成其它程序。
	5. 导出、预览、文件读取均加入白名单校验，不能再借助程序接口读取任意本机文件。
	6. 涉密模式不能被本地未认证请求静默关闭（关闭需要管理员权限）；涉密模式下会自动跳过本地 AI 调用。
	7. 本地 AI 服务地址默认只允许本机（localhost / 127.0.0.1 / [::1]），"测试连接"也只允许本机地址。
	8. 上传加入体积上限与合法性校验；批量导入加入数量上限与操作审计。
	9. 日志脱敏现在覆盖 UNC（\\服务器\共享）与 POSIX（/home/...）路径。

六、 数据与设置
	1. 字典、设置、涉密状态等用户数据统一迁移到 %LOCALAPPDATA%\标准处理系统\，安装到 Program Files 时也能正常保存（此前会因权限被系统重定向而"改完重启就变回去"）。
	2. 安装包不再包含字典与设置文件——它们是你自己积累与配置的数据，升级不会被覆盖。
	3. 本地 AI 可以直接在设置页（设置 → 安全 → 本地 AI）配置，并支持"测试连接"；系统环境变量 LOCAL_AI_URL 仍可用作回退配置。
	4. 版本号统一由 version.txt 单一来源管理，避免出现"安装包显示一个版本、程序里是另一个版本"。

七、 其它修复
	1. 修复了"给第 3 个文件设置页码范围、再拖入新文件后范围被静默切回第 1 个文件"的问题（页码面板与文件列表选中项现在共用同一状态）。
	2. 修复了前端等待上限低于后端处理时限导致的"假超时"：现在按"距上次进度变化"判定，并可通过"继续等待 / 查看已完成结果"处理。
	3. 修复了联网补充标准名称时绕过审核直接写入主字典的问题（现统一进入"待审核"）。
	4. 若干"点了没反应""提示成功但实际没生效"的静默失败已改为明确提示。
